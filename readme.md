# TypeLingo

TypeLingo 是一个根据中文母语提示跟打日语句子的纯前端练习应用。

练习区域固定为三行：第一行显示中文母语，第二行显示日语原句，第三行由用户使用日语输入法跟打。系统逐字符显示正确、错误和未输入状态，并记录实际完成句数和练习用时。

## 当前版本

v0.3 包含：

- 默认使用 egg rolls JLPT N1–N5 v3.5 卡组的 15,891 条日中例句与短语，原测试句库已移除
- 可选择卡组与 N5–N1 练习范围，每组随机选择最多 10 条
- 支持在浏览器中直接导入 Anki `.apkg`，自动识别例句字段，并可手动调整日语、中文与假名注音字段
- 导入前可预览例句、编辑卡组名称和介绍；导入的卡组保存在 IndexedDB，刷新后仍可使用
- 卡组详情显示介绍、作者、来源、版本、数量、等级分布、许可和内容整理说明
- 每句显示中文母语、日语原句和用户输入三行
- 可开启或关闭汉字上方假名注音，每轮练习默认开启
- 支持日语输入法的 IME 组合输入，不截断转换前的假名，也不把选词过程重复计错
- 严格检查汉字、假名和标点并逐字符反馈
- Backspace 修正，完成句子后按 Enter 继续
- 可选择“本次跳过该句”，只跳过当前一轮中的句子
- 可选择“永远跳过该句”，在之后的随机练习中排除该句
- 首页可以恢复当前卡组中全部永久跳过的句子，不影响其他卡组
- 记录实际完成句数和练习用时
- 使用 localStorage 保存最近 20 条日语练习成绩
- 使用 localStorage 保存永久跳过的句子
- 多标签页同步练习记录、永久跳过列表与导入卡组
- 导出 JSON 进度备份，并在另一台设备 / 浏览器中合并恢复
- 响应式布局、Sites 静态托管和 GitHub Actions 自动检查

## 本地开发

要求 Node.js 24 或更高版本。

```bash
npm install
npm run dev
```

常用检查：

```bash
npm test
npm run check
npm run build
```

## 练习与记录规则

- 只有输入内容与日语原句完全一致，并按下 Enter，才计为完成一句。
- “本次跳过该句”不会计入完成句数，也不会影响之后的练习。
- “永远跳过该句”不会计入完成句数，并会从之后的随机练习中排除；可在首页恢复全部。
- 计时从进入本轮练习开始，到完成或跳过最后一个句子为止。

## 发布

网站通过 Sites 静态托管，配置保存在 `.openai/hosting.json`。GitHub 源码仓库保持私有，推送到 `main` 会自动执行测试与构建。

项目使用相对资源路径，可部署在网站根目录或子目录。GitHub Actions 也保留可选的 GitHub Pages 发布流程；仅在仓库已启用 Pages 后，手动运行工作流并勾选 `deploy_pages`。

## 添加 Anki 卡组

1. 首页点击“添加 Anki 卡组”，选择 `.apkg` 文件。
2. 检查识别出的例句数量和预览。egg rolls v3.5 会自动识别 4 组例句字段。
3. 其他笔记模板若未自动识别，展开“查看 / 调整字段对应关系”，选择日语原句、中文翻译和可选注音，再点击“更新预览”。
4. 填写卡组名称、简单介绍，点击“添加并选择此卡组”。
5. 在首页选择卡组及练习范围，点击“开始练习”。

支持传统 `collection.anki2`、`collection.anki21`，以及使用 Zstandard 压缩和新版字段表的 `collection.anki21b`。解析在 Web Worker 中进行，文件不会上传到服务器；仅提取文本，不加载卡片模板脚本或媒体文件。

卡组需要提供日语原句和中文翻译字段。支持 Anki 的 `漢字[かんじ]` 注音和 HTML `<ruby>`；注音无法与原句对齐时保留原句，以无注音显示。原卡组中的关联词 / 反义词标记会被排除，日中句对会去重。学习进度、音频、图片和卡片模板不导入。

单文件上限为 512 MB，解压后的数据库上限为 64 MB，最多读取 10 万条笔记。特别大的卡组可在 Anki 中拆分。相同数据库文件重复导入会更新已有卡组；egg rolls v3.5 使用固定卡组标识。其他卡组重新导出后的数据库若发生变化，将视为另一套卡组。

## 进度备份与迁移

首页“最近成绩”下方提供“导出进度”和“恢复进度”。导出的 JSON 文件可保存在电脑的下载目录或手机的“文件”中，也可由用户自行保存到网盘。

- 备份包含最近 20 条成绩（卡组、时间、句数、用时）以及全部永久跳过的句子标识。
- 恢复会与当前浏览器的记录合并，去重后保留最新 20 条成绩；永久跳过记录取并集。
- 文件不包含卡组内容、音频、当前选中的卡组或尚未完成的本轮练习。自定义卡组请在新设备导入同一份原 APKG，才能对应其跳过记录。
- 支持 TypeLingo 版本 1 的进度备份格式，单文件上限 5 MB；错误文件不会被当作进度导入。
- 数据仍然保存在当前网站的浏览器本地存储中，没有自动上传或云端同步。

默认数据来自用户提供的 `egg_rollsJLPT_N1N5__v35NO_ENGLISH.apkg`，共 10,635 条词条。整理后保留 15,891 条例句与短语，其中 15,403 条带假名注音；排除 2,193 条关联词 / 反义词和 95 条重复句对。1 条注音无法对齐，保留原句而不显示其注音。

保留原句与中文翻译，改变了数据格式与呈现方式；没有导入媒体及 Anki 复习进度。完整署名、许可条件及修改说明见页面的“卡组详情”和 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

重新从原卡组生成内置 JSON：

```bash
node scripts/import-default-deck.mjs "path/to/egg-rolls.apkg"
```

运行此脚本会使用与浏览器导入相同的解析和转换逻辑，更新 `src/data/egg-rolls.json`。

## 内容格式

课程内容统一使用 JSON。`ruby` 将日语拆成若干片段；包含汉字的片段可以提供 `reading`，用于在汉字上方显示假名。

```json
{
  "schemaVersion": 2,
  "id": "my-deck",
  "title": "我的日语卡组",
  "nativeLanguage": "zh-CN",
  "targetLanguage": "ja",
  "items": [
    {
      "id": "my-deck-note-1",
      "nativeText": "妹妹在上高中",
      "text": "妹は高校に通っています",
      "ruby": [
        { "text": "妹", "reading": "いもうと" },
        { "text": "は" },
        { "text": "高校", "reading": "こうこう" },
        { "text": "に" },
        { "text": "通", "reading": "かよ" },
        { "text": "っています" }
      ]
    }
  ]
}
```

课程文件位于 `src/data/`。每个 `id` 必须唯一，且 `ruby` 中所有 `text` 拼接后的内容必须与句子的 `text` 完全一致。

## 项目限制

当前版本不包含用户登录、后端服务、云端数据库、在线排行榜或 AI/LLM API。

用户导入的卡组与练习记录只保存在当前浏览器中。清除网站数据、更换浏览器或更换设备可能导致数据丢失，请保留原始 APKG 文件。
